# Google / YouTube / Meta через KZ — применено

2026-10-30. Владелец попросил применить и кратко проверить, без расширенных тестов.
Уточнение: согласовано переключение **целых групп**, включая Facebook и остальные
домены Google. Это заменяет прежний выбор NL/DIRECT для трёх групп.

Решение: добавить reality-kz первым явным вариантом Google/YouTube/Meta,
сохранить прежние ручные варианты, выбрать KZ через API после reload (cache.db).
AI остаётся единственным KZ, основной Fallback и Fastest сохраняют NL.
При отказе KZ у select-групп нет автоматического перехода на другой выход.
Альтернативы: точечные домены отвергнуты владельцем; глобальный KZ не требуется.

Бэкап рабочего config/cache и selections в отдельный каталог, затем кандидат,
проверка парсером, hot-reload и выбор KZ. Закрыть старые соединения только этих
трёх групп. Приёмка: all/now API, живые TLS/chain для Google, YouTube/ytimg,
Instagram/Facebook; ответ HTTP отдельно от успеха TLS. Видеоплеер/reels может
полностью проверить владелец. Повторный тест отказа KZ не нужен.

Изменение существующего тестового контракта: разрешить KZ-достижимость только
AI и трём согласованным группам; первые proxies трёх групп — reality-kz.
Строгий AI-only и остальные проверки сохраняются. Новые тесты не требуются.

Возврат: Google→DIRECT, YouTube/Meta→Заблок. сервисы через API;
либо восстановить бэкап этого эксперимента (он уже KZ-only для AI), reload,
восстановить прежние selections. Ни в одном варианте AI не возвращается на US/NL.
ADR не требуется: пробное переключение существующих групп внутри 003.

## Результат — 2026-10-30, 21:19 МСК

Применено горячим перечитыванием, без рестарта XKeen. Google/YouTube/Meta:
now=reality-kz; прежние варианты сохранены для ручного возврата.
Закрыты 20 старых соединений групп и затем 13 старых Google-соединений.

Живая проверка обнаружила, что refilter перехватывал www.google.com раньше
правила Google и направлял его в NL. Правило Google перенесено выше refilter,
но ниже YouTube/Meta/AI. Повторная проверка с LAN 192.168.1.41:

| Хост | Цепочка | HTTP |
|---|---|---|
| www.google.com | Google → reality-kz | 200 |
| www.youtube.com | YouTube → reality-kz | 200 |
| i.ytimg.com | YouTube → reality-kz | 404 на корне |
| www.instagram.com | Meta → reality-kz | 302 |
| i.instagram.com | Meta → reality-kz | 404 на корне |
| www.facebook.com | Meta → reality-kz | 302 |

TLS успешно во всех шести случаях. Просмотр видео/reels в пользовательском
приложении не проверялся. Бэкап: backups/20261030-kz-google-meta/ и
/opt/backups/20261030-kz-google-meta/. Свидетельства: live-check.json в бэкапе.
