# Установка Entware/OPKG на USB-флешку (32 ГБ, Kingston DataTraveler 3.0) — пошаговый план

> Источник инструкции: support.netcraze.ru «Установка репозитория Entware на USB-накопитель»
> (см. `docs/sources.md`). Подготовка диска: Windows + DiskGenius. Роутер: KN-1811, aarch64.

## Важно перед началом

- **Флешка — только для системы Entware** (пакеты, конфиги). Торренты/запись — на HDD/SSD:
  флеш-память быстро изнашивается (решение из `docs/router.md`).
- RAM роутера 512 МБ → **SWAP-раздел желателен** (аварийная подушка против OOM-killer
  при Xray/Transmission; строго не обязателен, но добавить потом = переразметка).
  Сделан **2 ГБ** (решение владельца — с запасом).
- **Работа с USB-носителями — через DiskGenius в Windows.** Проброс в WSL через usbipd-win
  запрещён (см. `AGENTS.md`: нестабильный канал, ложные ошибки ввода-вывода).
  Файлы на ext4-раздел класть через SMB-шару роутера (браузер файлов DiskGenius
  зависает при записи в ext4 — не использовать).

## Шаг 1. Бэкап конфига роутера (обязательно)

Веб: Управление → Конфигурация → Сохранить → файл в `backups/` (в git не коммитить).

## Шаг 2. Компонент ОС «Поддержка открытых пакетов»

Веб: Общие настройки → Изменить набор компонентов → «Поддержка открытых пакетов (OPKG)»
→ установить, дождаться перезагрузки. (Другие OPKG-компоненты не нужны на старте.)

## Шаг 3. Флешка в роутер

USB-порт роутера. Веб → Приложения → Диски и принтеры: диск должен появиться (ENTWARE, ext4).

## Шаг 4. Установщик Entware на диск (через SMB)

1. Веб → Приложения → SMB-сервер: включён, общий доступ к ENTWARE открыт
   (встроенный SMB KeeneticOS нормально пишет в ext4).
2. С ПК открыть шару: `\\192.168.1.1` → раздел ENTWARE.
3. Создать в **корне раздела** папку `install`.
4. Скопировать туда `aarch64-installer.tar.gz` (уже скачан на Windows:
   `C:\Users\baira\Downloads\entware\`; источник —
   https://bin.entware.net/aarch64-k3.10/installer/aarch64-installer.tar.gz).

## Шаг 5. Установка Entware

Веб → **Менеджер пакетов OPKG**:
- Накопитель: выбрать наш ext4-раздел;
- «Доступ для учетной записи пользователя»: **включено**;
- Сохранить.

Установка идёт автоматически; прогресс — Диагностика → Системный журнал:
ждём `installer: [5/5] Установка системы пакетов "Entware" завершена!`.
В логе также будет строка с портом SSH и паролем по умолчанию.

## Шаг 6. Первый вход по SSH

Логин `root`, пароль по умолчанию `keenetic`.
Порт: **22** — у нас компонент «Сервер SSH» на роутере НЕ установлен
(если поставим позже — Entware переедет на 222; сверяться с логом из шага 5).

## Шаг 7. Смена пароля, обновление и проверки

```sh
passwd                 # сразу сменить пароль root
opkg update            # обновить список пакетов
```

- Swap: веб → Приложения → Диски → «Раздел подкачки активен» (или `free` в Entware-SSH).
- `opkg list-installed` — базовые пакеты на месте.
- Роутер: `show usb`, `show ip hotspot` — ничего не отвалилось.

## Шаг 8. Сохранить конфиг роутера

CLI: `system configuration save` (без этого настройки OPKG слетят при перезагрузке).
Файл-паспорт `docs/router.md` обновить: Entware установлен, порт SSH, диск.

## Откат (если что-то пошло не так)

- Менеджер пакетов OPKG → накопитель «Не выбран» → Сохранить;
- либо полное отключение компонента OPKG;
- флешку переформатировать в DiskGenius. Конфиг роутера восстанавливается из бэкапа шага 1.

## Бэкапы: 3 слоя, что чем восстанавливается

| Слой | Что | Бэкап | Восстановление |
|---|---|---|---|
| 1 | ОС + компоненты | `firmware.bin` (backups/) | загрузка bin в вебе |
| 2 | Настройки роутера | `startup-config.txt` (backups/; перескачивать после крупных изменений!) | «Заменить файлом» |
| 3 | Содержимое флешки (/opt) | НЕ входит в bin! Образ раздела через DiskGenius Backup Partition или `tar czf` по SSH | заливка образа / распаковка tar |

- Entware сам переустанавливается за ~15 мин; ценны: кастомное приложение, его БД, конфиги —
  копировать отдельно и чаще (в облако — только зашифрованным архивом).
- Копирование по SMB на ПК НЕ сохраняет симлинки/права — не годится как полный бэкап /opt.
