## Сеть

- Управляющий Mac: en0, 192.168.1.x, шлюз 192.168.1.1. Пинг на роутер блокируется —
  доступность проверять по HTTP, не по ICMP.
- CLI доступен и по Telnet (в KeeneticOS встроен; порт 23) — при подключении проверить,
  но для работы предпочитать SSH (Telnet — открытый канал).
- На Mac есть point-to-point VPN-интерфейс (192.168.144.0/22): он может мешать curl к роутеру —
  при проблемах указывать `--interface en0`.
- Mesh: 2 дополнительных узла Keenetic (модели/имена уточнить при первом подключении).
  Backhaul-настройки не трогать без явной задачи.

## Заполнить при первом подключении (CLI)

```sh
show version        # модель, версия OS, SDK — сюда
show system         # аптайм, температура, память
show running-config # > бэкап в backups/ перед ЛЮБЫМИ правками
show components     # список установленных компонентов (через веб: Изменить набор компонентов)
show usb            # USB-диски
show ip hotspot     # известные устройства LAN (для сплита трафика)
show ip policy      # политики (база для сплита через XKeen)
```

## Полезное (из печатной инструкции Ultra; буклет был для KN-1810 — удалён)

- **Кнопки FN1/FN2** (по умолчанию) — безопасное отключение USB-накопителей перед извлечением;
  индикаторы FN1/FN2 отражают готовность USB-устройств. Переназначаются в настройках.
- **Порт 0 — WAN** (на KN-1810 — комбо RJ-45+SFP; на KN-1811 — 2.5GE, наличие SFP-комбо
  уточнить осмотром). Порты 1–5 — LAN по умолчанию, но любой можно перенастроить под WAN/IPTV.
- **Сброс к заводским**: удерживать Reset 10 сек (сброс и пароля админа).
- Кнопка Wi-Fi: однократно — WPS, удержание 3 сек — вкл/выкл Wi-Fi.
- USB-диски: NTFS/FAT32/exFAT/EXT2–4/HFS+. По умолчанию из USB-приложений включён только
  SMB-файловый сервер; Transmission/FTP/DLNA — включаются в веб-интерфейсе (Менеджер приложений).
- **Флешки под торренты не использовать** (износ) — только HDD/SSD.
- Для SMB-прав доступа — компонент «Контроль доступа к папкам»; для Time Machine — «Общий доступ
  к файлам (AFP/Time Machine)».
- Питание 12 В / 3 А; веб-конфигуратор также доступен по my.keenetic.net; приложение My.Keenetic.


## Бэкап/восстановление

- Снять: веб (Управление → Конфигурация → Сохранить) или CLI `copy running-config flash:`.
- Хранить копию локально в `backups/` (в git не коммитить — там могут быть пароли).
- Перед включением «Сервера SSH», установкой OPKG/Entware и любыми экспериментами — бэкап обязателен.
